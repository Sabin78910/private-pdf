# Play Console: Data safety and app content answers

Paste into **Play Console → Policy → App content**. Matches the privacy policy section `#private-pdf`.

## Data safety
- **Does your app collect or share any of the required user data types?** **No.**
  - Documents, images, OCR text and job history are processed and stored only on the device. The app has
    no server; nothing is transmitted to the developer or any third party.
  - Optional Google sign-in: Google's sign-in service returns the user's name and email to the app, which
    keeps them **on the device only** to show who is signed in. Play counts data as "collected" only when it
    is sent off the device, so this is not collected. Sign-in itself is between the user and Google.
- **Is all user data encrypted in transit?** Not applicable (no data leaves the device; sign-in uses Google over HTTPS).
- **Deletion:** Users can sign out and clear history in the app; uninstalling removes everything.

## Permissions to explain if asked
- **CAMERA**: only when the user taps "Take photo" in Scanner or OCR.
- **INTERNET**: only for optional Google sign-in. All tools work offline.

## Other app content
- **Ads:** No ads.
- **Target audience:** 13+ (general audience productivity app; not designed for children).
- **Content rating (IARC):** Utility/productivity, no user-generated sharing, no chat, no purchases → expected *Everyone / PEGI 3*.
- **Government app:** No (not affiliated with any government). **Financial features / health:** No.
- **News app:** No. **Account deletion:** No developer accounts exist; Google sign-in can be removed by signing out.
- **Privacy policy URL:** https://sabin78910.github.io/privacy-policy/#private-pdf
